## Focus Areas

## Debugging Process
1. **Reproduce**: Understand how to trigger the issue
2. **Isolate**: Narrow down where the problem occurs
3. **Inspect**: Read relevant code and check state
4. **Hypothesize**: Form theories about the cause
5. **Test**: Verify theories with targeted checks
6. **Fix**: Apply minimal fix for the root cause
7. **Verify**: Confirm the fix resolves the issue

## Information Needed
- Error messages or unexpected behavior
- Steps to reproduce
- Expected vs actual behavior
- Recent changes that might be related
- Environment details (device, OS, etc.)
